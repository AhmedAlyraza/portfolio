# Ahmed Ali — Portfolio Website

A responsive single-page portfolio website built with HTML, CSS and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

## Publish using GitHub Pages
1. Create a **public** repository named exactly `AhmedAlyraza.github.io` (GitHub usernames are case-sensitive in the repository field).
2. Upload the files in this folder (`index.html`, `styles.css`, `script.js`) to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Your portfolio will be available at `https://ahmedalyraza.github.io/`.

## Personalize before publishing
- In `index.html`, replace the LinkedIn link `https://www.linkedin.com/` with your actual profile URL.
- Review project names/descriptions and only keep entries you are comfortable sharing publicly.
- You may add project demo and repository links to project cards.
- Check your phone number and email before publishing.
